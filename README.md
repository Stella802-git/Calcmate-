
⚡ CalcMate

A simple, interactive calculator built with HTML, CSS, and JavaScript.

✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Decimal number support
- Clear button to reset calculations
- Division-by-zero error handling
- Neon-inspired user interface

🛠️ Technologies Used

- HTML – Structure of the calculator
- CSS – Styling, layout, and visual effects
- JavaScript – Calculator functionality and mathematical operations

🎨 Design

CalcMate features a neon-futuristic design with a dark background, glowing colours, and interactive buttons.

🎯 Project Goal

This project was created to practise web development, improve my CSS and Javascript skills, and learn how HTML, CSS, and JavaScript work together to build an interactive application.

🚀 How to Use

1. Open https://comfy-pudding-fc8ae5.netlify.app in a web browser.
2. Enter a number.
3. Choose a mathematical operator.
4. Enter the second number.
5. Press "=" to see the result.
6. Press "C" to clear the display.
